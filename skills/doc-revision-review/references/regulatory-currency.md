# Regulatory and standards currency

> **This file is a convenience aid, not a controlled standards register.**
> It was assembled from public sources on the dates in the Verified column. It
> is not maintained automatically and it will drift. Before any finding from
> this file is acted on, reconcile it against the company's controlled list of
> approved standards and editions.
>
> **How to use it:** look up a citation found in the document. If this file says
> the cited edition is superseded, **confirm by web search before reporting it**,
> then report it as an orange recommendation with the words "confirm against the
> controlled standards list". If a search cannot confirm it, report **REVIEW**,
> not FAIL. Never invent an edition year, and never report a standard as
> superseded on the strength of this file alone.

Baseline assembled 2026-11-13.

## Phrases worth flagging regardless of edition

These are wording problems rather than edition problems, and they do not need a
web search to raise:

- "Quality System Regulation" or "QSR" used as the current title of 21 CFR Part 820 (it is the QMSR since 2 February 2026).
- "IVD Directive", "IVDD" or "98/79/EC" described as the applicable EU legislation.
- "MDD" or "93/42/EEC" described as the applicable EU legislation.
- A standard cited with no edition year at all, where the document's purpose requires a specific edition (verification protocols, declarations of conformity, essential-requirements checklists).
- A standard cited with an edition year in one section and a different year in another section of the same document — that is a check 5 internal conflict, and it needs no external lookup.
- "FDA 510(k) cleared" or "CE marked" stated for a product the document elsewhere describes as IUO or RUO.
